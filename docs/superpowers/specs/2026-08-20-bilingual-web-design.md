# Agent Market 整站中英双语设计

## 目标

为 Agent Market 的全部 Web 路由提供中文与英文界面，同时保持现有 Edge SSR、精确 hydration、客户端故障降级和 Evidence 真实性边界不变。

## 范围

- 覆盖全局导航、页面标题、说明、按钮、状态标签、空状态、错误页和 Evidence 页面。
- 覆盖当前 15 个 Web 路由及真实 404 页面。
- 架构图、时序图中的协议名、服务名和代码路径保留英文，外围说明提供双语。
- 不翻译用户输入、链上数据、Agent 名称、任务内容、交易哈希、ARN、URL 或代码标识符。

## 架构

新增独立的 `i18n` 模块，包含：

- `Locale` 类型：仅允许 `en` 与 `zh-CN`。
- 类型安全翻译字典：英文为基准结构，中文必须覆盖相同键。
- `LanguageProvider`：向组件树提供当前语言、切换方法和翻译函数。
- `LanguageToggle`：在全局 Shell 中提供 `中文 / EN` 控件，并满足键盘操作与触控尺寸要求。

页面组件只引用翻译键，不自行读取浏览器语言或存储。

## SSR 与 hydration

服务端渲染和浏览器首次渲染固定使用英文，确保 HTML 与 hydration 输入完全一致。hydration 完成后，Provider 在 effect 中读取 `localStorage`；存在有效偏好时切换，否则保持英文。用户主动切换后写入 `localStorage`，仅保存非敏感语言标识。

不根据请求头、时区或浏览器语言在服务端分支，避免缓存碎片和 hydration mismatch。严重 hydration 失败仍沿用现有单次 CSR fallback。

## 数据与状态

业务数据字段保持原值。枚举状态通过统一翻译映射显示，例如 `VERIFIED`、`IMPLEMENTING` 和 `BLOCKED`；Evidence ledger 中的原始状态不修改。这样展示语言不会改变证据语义或验证逻辑。

## 错误处理

- 找不到翻译键时回退到英文并保留可读内容。
- `localStorage` 不可用时静默保持英文，不阻断页面。
- 非法存储值被忽略。
- 切换语言不触发网络请求，也不影响钱包、任务或性能上报状态。

## 验证

- 单元测试：字典键一致、非法偏好回退、切换与持久化。
- SSR 测试：英文服务端输出与首次客户端状态一致。
- 路由测试：关键页面英文和中文文案均可访问。
- 生产检查：`/evidence`、任务工作台与 404 保持正确状态码及 `x-agent-market-render-mode: ssr`。
- 响应式检查：375、390、430 与 1440 px 下切换控件无横向溢出。

## 非目标

- 本期不引入第三方翻译 SaaS、自动机器翻译、服务端 locale 路由或 `/zh`、`/en` URL 前缀。
- 本期不翻译 SVG 内部文字；避免重新生成已验证架构资产。
- 本期不增加新的认证、数据库字段或 Cloudflare/AWS 资源。
